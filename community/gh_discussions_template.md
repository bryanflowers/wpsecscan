# GitHub Discussions — categories + templates

Round-64 #132 — copy these into the repo's Discussions settings.

## Categories

### 📣 Announcements (announcement)
*Release notes, project news. Maintainers only.*

### 🙋 Q&A (q&a)
*Ask a question, get an answer. Marked as answered when resolved.*

### 💡 Ideas (idea)
*Propose a new check, integration, or feature.*

### 🐛 Bug reports (bug)
*Suspected bugs. If it's clearly a bug, prefer Issues; if uncertain, here.*

### 🛡️ Security (security)
*PUBLIC security discussion only. Real vulnerabilities go to
security@wpsecscan.com — see SECURITY.md.*

### 🎓 Show & tell (show-and-tell)
*Share how you use WPSecScan: writeups, dashboards, integrations.*

### 🏆 CTF / challenges (ctf)
*WPSecScan CTF challenge solutions + discussion.*

## Templates

### Bug report template

```markdown
**WPSecScan version:** (e.g. 2.2.0, run `wpsecscan --version`)
**OS:** (Windows 11 / Ubuntu 22.04 / macOS 14)
**Python version:** (output of `python --version`)

**What I did:**
1. ...
2. ...

**What I expected:**
...

**What actually happened:**
...

**Full output (with `--verbose`):**
```
[paste here]
```

**Have you searched existing issues?** yes / no
```

### Feature idea template

```markdown
**Problem:** what's the pain point?
**Proposed solution:** in plain English
**Who benefits:** which user persona?
**Alternatives considered:**
**Willing to PR?** yes / no
```

### Q&A template

```markdown
**Goal:** what are you trying to do?
**What you tried:** include commands + output
**Where you're stuck:** specific error or unexpected behaviour
**Environment:** OS, WPSecScan version
```
