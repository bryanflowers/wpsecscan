# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text version is also at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

## TL;DR

- Be respectful and constructive in issues, PRs, discussions, and chat.
- Assume good faith. Disagree on technical merits, not on people.
- Maintainers may edit, hide, or remove any contribution that conflicts
  with the Covenant.

## Scope

The Code applies to all project spaces (this repository, its issue
tracker, discussions, and any official chat / mailing list) and to
public spaces where an individual is representing the project.

## Enforcement

Report unacceptable behaviour to **bryaninbangkok@gmail.com**.

Reports are reviewed within 5 business days. Reporters' identities are
kept confidential. The maintainers will respond with one of:

- No action (the report doesn't describe a Covenant violation)
- Private warning to the participant
- Temporary or permanent ban from project spaces
- Removal of the offending content

The maintainers' decisions are final for this project. If you disagree
with an enforcement decision, you may appeal once by replying to the
original notification.
