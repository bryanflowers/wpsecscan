# Monthly webinar — template

Round-64 #156 — slide-by-slide outline for the monthly community
webinar.

## Title

`What's new in WPSecScan + {{MONTH YEAR}} threat round-up`

## Length

45 min: 30 talk + 15 Q&A.

## Slides

### 1. Title + housekeeping (1 min)
- Greeting, hosted by who
- Recording will be posted publicly
- Link to chat for Q&A

### 2. What shipped this month (5 min)
- New checks (list)
- New integrations
- Bug fixes worth calling out
- Demo: one new feature live

### 3. Threat round-up (10 min)
- Top 5 new CVEs (severity + plugin install base)
- Any in-the-wild exploitation observed
- WPSecScan check that detects each

### 4. Deep dive (10 min)
- One feature OR threat, in depth
- Live demo + remediation walkthrough
- Code/CLI demonstrations welcome

### 5. Community shout-outs (3 min)
- Top contributors this month
- Show & tell submissions
- CTF winners

### 6. What's next (2 min)
- Roadmap teaser
- Next month's webinar topic

### 7. Q&A (15 min)
- Take from chat
- "If we have time" pre-submitted questions

## Pre-webinar checklist (T-7 days)

- Topic + speaker confirmed
- Slides drafted
- Demo environment tested
- Discussion-post created on GitHub Discussions
- Calendar invite published
- Social posts queued

## Day-of checklist

- Test audio/screen-share 30 min before
- Open chat in a second monitor
- Have a "thanks for joining" slide ready
- Set up recording

## Post-webinar (within 48h)

- Upload recording to YouTube + Internet Archive
- Post chat-based Q&A in the discussion thread
- Newsletter feature in next month's edition
